# BFG Progression System

## Philosophy

Progression in BFG is emotional.

The goal is not only numeric growth.

The goal is to create:

- movement

- continuity

- evolution

- emotional satisfaction

- visible change

The user should feel:

- stronger

- more complete

- more connected to their path

---

## Core Progression Pillars

- XP

- levels

- streaks

- avatar evolution

- titles

- emotional milestones

---

## XP Philosophy

XP represents movement and consistency.

XP should feel:

- rewarding

- visible

- meaningful

Avoid:

- giant XP inflation

- meaningless numbers

- grinding feeling

---

## Leveling Philosophy

Levels represent evolution of the user's journey.

Level ups should feel:

- calm

- important

- earned

- emotional

Avoid:

- arcade-style dopamine spam

- excessive effects

- aggressive reward loops

---

## Streak Philosophy

Streaks represent continuity.

Streaks should:

- encourage return

- reinforce movement

- create emotional attachment

Streaks should never:

- create shame

- punish absence harshly

Returning should always feel safe.

---

## Reward Philosophy

Rewards should create:

- completion

- pride

- emotional recognition

Rewards are not only currency.

Rewards include:

- titles

- companion reactions

- avatar evolution

- emotional moments

- visual changes

---

## Emotional Milestones

Important moments should feel personal.

Examples:

- first workout completed

- return after absence

- 7-day continuity

- evolution unlock

- long-term consistency

These moments should feel:

- calm

- meaningful

- emotionally memorable

---

## Avatar Progression

Avatar progression should feel:

- gradual

- alive

- emotionally connected

Evolution includes:

- aura growth

- glow intensity

- stance confidence

- energy effects

- subtle visual upgrades

---

## MVP Progression System

MVP progression includes:

- XP

- levels

- streaks

- daily quests

- titles

- avatar visual evolution

- emotional companion reactions

Avoid:

- complex economies

- skill trees

- stat systems

- competitive ranking systems

---

## Core Emotional Goal

At the end of the day, the user should feel:

- completion

- pride

- movement

- continuity

Not pressure.

Not exhaustion.

The path continues.
