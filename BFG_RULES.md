## Core Rule

Build only MVP systems that improve the emotional core loop.

Avoid overengineering.

---

## Architecture Rules

- Keep components simple

- Avoid unnecessary abstractions

- Avoid complex patterns

- Avoid premature optimization

- Avoid enterprise architecture

Prefer:

- simple logic

- readable code

- fast iteration

- small components

---

## UI Rules

- Mobile-first

- Minimalistic layouts

- Emotional atmosphere over visual complexity

- Reusable UI components

- Avoid overdesigned interfaces

---

## State Management Rules

Use simple local state first.

Only introduce global state when necessary.

---

## AI Rules

AI companion should:

- be calm

- minimalistic

- emotionally aware

- atmospheric

Never:

- toxic motivation

- aggressive coaching

- cringe positivity

---

## Avatar Rules

Avatar evolution should:

- feel emotional

- feel earned

- create attachment

Focus on:

- aura

- glow

- stance

- energy

Avoid:

- complex 3D systems in MVP

---

## Development Philosophy

Speed > perfection.

Playable emotional loop > feature quantity.

Retention > feature count.

Consistency > complexity.
