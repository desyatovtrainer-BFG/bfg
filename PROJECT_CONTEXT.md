# BFG Project Context

## Project Name

BFG — Big Fitness Game

---

## Product Type

Gamified fitness web app focused on:

- emotional progression

- consistency

- avatar evolution

- AI companion

- daily continuity

---

## Core Emotional Goal

The user should feel:

- stronger

- connected

- emotionally supported

- visually evolving

BFG is not a fitness tracker.

BFG is a self-evolution system.

---

## MVP Priorities

Current MVP focus:

- auth

- progression

- avatar evolution

- daily quests

- AI companion

- workout completion loop

---
